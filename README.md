# 奶蛙牌 Naiwa Poker

用掼蛋牌型打的肉鸽卡牌游戏：凑牌型、压住对手的牌、攒一队奶蛙伙伴，从打 2 一路打到打 A。

- 直接打开 `index.html` 就能玩（横屏）
- B站 Toy 安装包在 [`download/`](download/) 里

## 当前版本 v0.5

- 13 站、13 个首领，每个首领有自己的机制；打败首领后可以收下它的进贡牌
- 122 个伙伴、22 张符咒、10 个秘宝
- 玻璃 / 钢 / 双生 / 变色 / 幸运 / 冰心六种增强，六种印
- 6 个主角、9 级难度、无尽模式、B站排行榜和云存档
- 31 个成就，攒成就解锁 5 款牌背；图鉴分伙伴 / 符咒秘宝 / 首领 / 对手四页
- 17 首背景音乐
