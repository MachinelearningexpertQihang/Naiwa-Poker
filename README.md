# 奶蛙牌 Naiwa Poker

用掼蛋牌型打的肉鸽卡牌游戏：凑牌型、压住对手的牌、攒一队奶蛙伙伴，从打 2 一路打到打 A。

- 直接打开 `index.html` 就能玩（横屏）
- B站 Toy 安装包在 [`download/`](download/) 里

## v2.3

- 13 站、13 个首领，每个首领有自己的机制；打败首领后可以收下它的进贡牌
- 155 个伙伴、22 张符咒、10 个秘宝
- 玻璃 / 钢 / 双生 / 变色 / 幸运 / 冰心六种增强，六种印
- 6 个主角、9 级难度、无尽模式、B站排行榜和云存档
- 31 个成就，攒成就解锁 5 款牌背；图鉴分伙伴 / 符咒秘宝 / 首领 / 对手四页
- 17 首背景音乐
- 1.0 新增：小关和大关可以跳过，换一个随机奖励；站与站之间有路上的小事件（茶摊、赌骰子的老奶蛙、帮首领跑腿……）；结算页可以生成战绩图
- 1.1 新增：每张扑克牌都有自己的奶蛙（♠奶蛙 ♥奶猫 ♣奶鸡 ♦奶马）；新牌型「两对」，手牌 11 张；炸弹越多越响；每日挑战和日榜；存档三层（本机 + 本机备份 + 云端）和在线时长；竖屏自动转过来
- 1.2 新增：伙伴和手牌都能按住拖动调顺序（和小丑牌一样）；伙伴从左往右依次生效；自己排过的手牌，新摸的牌接在后面，点「按大小 / 按花色」恢复自动排序
- 1.3 新增：每一局记录总伤害，打牌时左上角实时显示「本局总伤害」，结算页和战绩图都能看到；记下最高的一局（破纪录会提示）和一共打出过的伤害，菜单里能看到
- 1.4 新增：无尽模式每打完一轮三选一奖励（伙伴栏 +1、牌型全升级、出牌 +1、传说伙伴、金币），横幅写着下一个目标；无尽和总伤害成就 5 个；排行榜加「总伤害」榜（4 号）；商店里伙伴标出买下后流派凑到几个；左边栏铺满整列
- 1.5 存档向奶蛙之塔看齐：云端连不上自动重试、上传失败自动重传、只传有变化的部分；云端和本机合并时每一项取更好的那份；设置里能看到云存档状态、上次同步时间，还有「从云端找回存档」；本机存储写不进去会改存到备份区并提醒
- 1.6 新增：22 个新伙伴（路上打过的对手跟你走了）；商店买东西先弹确认；屏幕比 16:9 宽或高时背景铺满两边，不再有黑边；商店的流派标签挪到牌下面；伙伴流派套装先去掉（流派保留）
- 1.7：屏幕适配回到 1.5 的样子；伙伴流派套装回来了但更低调——凑齐 3 个同流派，这几张伙伴边缘一起泛淡淡的金光，卡槽里会挨在一起、拖动时一起移动，商店里不再写 x/3；长按任何一张扑克牌（手牌、牌组、卡包、首领进贡）弹出说明，讲清楚玻璃牌、钢牌、印、闪卡、逢人配、级牌、进贡牌都是什么
- 1.8：新牌型「同花」（同一花色任意 5 张）；王牌流 5 个新伙伴让大小王有用起来（凑齐 3 个：每张王 倍率 ×1.5）；商店同一家店里越刷越容易出稀有 / 史诗 / 传说；茶包偏向你常出的牌型；符咒牌面多了内框、小菱形、圆环和纸纹
